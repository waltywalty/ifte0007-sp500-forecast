# Copyright, attribution and permitted reuse

This governs prose, comments, code, figures, tables, screenshots, recordings, fonts/templates, AI traces and financial artifacts in GitHub, group circulation and submission.

Citation is not copying permission. Education/private hosting is not a blanket exception. A relied-on exception needs its actual purpose, necessary extent, acknowledgement and sharing assessed; no word-count/percentage guarantees fair dealing. [UK IPO guidance](https://www.gov.uk/guidance/exceptions-to-copyright)

| Material | Required treatment |
|---|---|
| Writing | Independent explanation; cite ideas/methods/claims; avoid close paraphrase |
| Quotes | Mark, pinpoint source and document permitted basis |
| Figures/tables | Prefer reproducible own scripts/permitted inputs; credit sources/adaptations |
| Screenshots | Necessary permitted content only; remove private details |
| Adapted code | Upstream URL/revision/licence/modifications; retain notices |
| Dependencies | Separate install; review before redistributing source/binaries |
| Fonts/templates/logos | Document intended-use rights; downloadability is insufficient |
| Data/outputs | Review local research, GitHub, group, ZIP and public destinations separately |
| AI assistance | Disclose, verify references and review copied-looking passages/snippets |

Redrawing charts or independently plotting restricted data does not automatically clear distribution. Prefer links/original summaries to copied articles, teaching documents or lengthy extracts. UCL distinguishes private study from sharing copies. [UCL student guidance](https://www.ucl.ac.uk/library/learning-teaching-support/ucl-copyright-advice/copyright-students), [UCL FAQs](https://www.ucl.ac.uk/library/learning-teaching-support/ucl-copyright-advice/faqs)

## Registers and licensing

Use [rights register](../evidence/manifests/rights_register.json): path/hash, origin, known creator/holder, source/licence URL, copied/adapted/generated status, permission basis, destinations, required notices, reviewer/date/status. Pending/excluded items cannot enter affected exports. Record the actual basis, not universal clearance. Packaged register metadata is an approved included subset, not an automatic copy of unrelated/pending entries or unreviewed extra fields.

Use [references.bib](references.bib) as canonical bibliography; add nearby citations. [Third-party notices](../THIRD_PARTY_NOTICES.md) preserve incorporation obligations, not replace scholarly references.

Do not automatically apply MIT, Creative Commons or another blanket licence. Establish authority over group contributions and distinguish external material/restricted data. AI use does not resolve ownership or certify originality. [GitHub licensing](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)

## PR/release gate

Identify external material, verify citations/quotation boundaries, register destination/rights, preserve notices, run manifest checks and obtain human review of similarity/licence/exception interpretation. Exclude unclear items and use an original explanation, source link or cleared alternative.

Checks detect incomplete records/boundary failures; they cannot certify non-infringement or plagiarism-free text. Do not upload restricted material to external similarity/AI services to check it. Necessary external clarification is for the group to send.

If an issue emerges, stop affected distribution and record an authorised correction/withdrawal. Preserve lawful audit metadata without treating provenance as permission for continued unauthorised distribution.
