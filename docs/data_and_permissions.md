# Data and permissions

Initial contents are authored code/docs and invented fixtures. Public downloads, university access and private hosting do not establish sharing permission. See [copyright](copyright_and_attribution.md).

| Input | Authority/distribution | Treatment |
|---|---|---|
| S&P USD price index | S&P Dow Jones Indices via FRED SP500 | Exact identity; empirical export needs documented basis |
| VIX | Cboe via FRED VIXCLS | Percentage-point units; source-specific reuse review |
| VIX3M | Cboe via FRED VXVCLS | Common-availability guard, not fitted predictor |
| Synthetic fixtures | Project-authored invented values | Mechanics only |
| WRDS/Compustat | Vendor/university subscription | Private files closed and excluded |
| Protected crypto/other work | Separate research | No holdout/unrelated import |

[FRED SP500 notes](https://fred.stlouisfed.org/series/SP500) identify restrictions; a download is not a licence. [WRDS AI policy](https://wrds-www.wharton.upenn.edu/pages/about/ai-policy-on-chatgpt-and-other-generative-ai-tools/) is separate; no protected-instance/vendor exception is presumed here.

For empirical inputs retain identity, units, source URL, observed/publication/availability/retrieval timestamps, permitted use and raw hash. Date labels alone do not prove availability. Preserve raw receipts in authorised operations; sanitise private headers/authentication URLs before any permitted export.

The [rights register](../evidence/manifests/rights_register.json) records each artifact/hash, source, basis, destinations, notices, review and status. Data, ledgers, coefficients and figures may need distinct treatment. One destination does not imply another.

Distinguish synthetic demonstration, actual arithmetic replay, full empirical refit and genuine source delivery. The brief's labelled-sample route does not grant provider rights or make a sample equivalent to the full study. Explain omissions and reproduction limits.

Use explicit allowlists. Reject pending/excluded/changed files. No credentials, cookies/tokens, private exports or unrelated histories. For unclear rights use links, original explanation or cleared alternatives; the group sends any clarification. Small/non-confidential/manual downloads are not automatically cleared.
